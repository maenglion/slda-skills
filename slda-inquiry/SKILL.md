# SLDA Inquiry Expansion v0.1

상속: `slda-core`. verdict_mode = `determine`(신청서 문서군의 구조 판정). **법 위반은 확정하지 않는다** — 신청서만으로는 개인정보보호법·민소법 위반이 성립하지 않으며, 법원 허가·회신 범위·취득 후 처리가 확인돼야 한다.

## 1. 분석 단위

문서 1건이 아니라 **결합 단위** 1행:
`대상자 · 정보종류(금융/과세/고용/기관평가) · 기간 · 명시된 입증명제 · 법적 평가어 · 요구범위`
한 신청서에 대상자가 둘이면 2행. 회신 자료(실제 유입된 분량·쪽수)는 별도 행으로 등재해 "좁힐 기회"의 기준점으로 쓴다.

## 2. 침해 강도축 0–5 (주장 세기와 별개 척도)

| 값 | 정의 |
|---|---|
| 0 | 공개정보 확인 |
| 1 | 특정 사실 확인 |
| 2 | 제한적 제3자 자료 |
| 3 | 장기간·다기관 개인정보 |
| 4 | 비당사자 전면자료 + 위법 가설 |
| 5 | 범죄 확정형 서술을 전제로 한 전 생활·사업영역 탐색 |

소수점 0.5 허용. **주장 세기 사다리(core §2)와 혼동 금지** — 이 축은 요구범위의 침해성이며, 법적 평가어의 세기는 별도 열로 기록한다. 두 열이 어긋나는 행(`평가어 낮음 + 범위 큼` = 탐색형 / `평가어 단정 + 범위 큼` = 가설확정형)이 핵심 관찰 대상이다.

## 3. 시간축 표 (고정 열)

`시점 · 대상·수단 · 명시된 입증명제 · 범위 · 강도 · SLDA 판정(1문장)`. 판정 문장은 "입증보다 발견 기능이 큼", "계좌는 특정했지만 문제거래 전후가 아니라 전체 자금흐름으로 확대" 같은 **범위–명제 간극 서술**만. 동기 서술 금지.

## 4. 단계 서술 (주장 강도의 변화)

시간순으로 3–4단계. 각 단계: 무엇을 찾는 단계인가 / 명제의 주어가 누구인가 / **의미** 1문장(`주장 강도 ↔ 자료범위` 조합으로 기술). 주어가 당사자에서 비당사자 법인으로 이동하는 지점을 반드시 표시.

## 5. 드리프트 D-nn (5 유형 고정)

| 코드 | 이름 | 검사 |
|---|---|---|
| D-01 | 입증대상 드리프트 | 초기 명제 / 후기 명제 / **빠진 연결고리**(손해·인과관계) |
| D-02 | 확인과 단정의 왕복 | 동일 시점 문서군 내 "위반 여부 확인" ↔ "~을 위하여 설립된" 단정 병존 |
| D-03 | 범위 비대칭 | 문제 삼는 핵심(특정 거래) vs 요구 자료(회사 전체 관계망) |
| D-04 | 보호 문구의 역설 | "필요 시 가림" 언급 + "반드시 포함" 요구 동시 존재 → 최소수집 설계를 법원·기관에 전가 |
| D-05 | 자료 확보 뒤 정밀화 부족 | 회신 후 후속 신청이 축소됐는가 확장됐는가 |

D-05의 추론은 "~로 읽힐 여지가 있다"까지. 동기 확정 금지를 명기.

## 6. 법적 시사점 — 트랙 분리 서술

개인정보보호법 / 민사소송법 / 금융·과세 비밀보호 / 명예·인격권 순으로 **각각 별도 소절**. 트랙 간 프레이밍 혼용 금지(core §7).
- 개보법: 법원 명령은 제공 근거가 될 수 있음을 먼저 적고, 별도 심사 지점 3개(최소범위·비례성 / 제공 후 목적 외 이용 / 비당사자 식별정보)만 등재. 가장 정확한 표현은 "위반 확정"이 아니라 **"과도한 취득을 초래할 수 있는 광범위한 증거신청 + 취득 후 목적 제한 필요성"**.
- 민소법: 증명할 사실의 불특정성 / 문서 표시의 포괄성 / 필요성·관련성 미폐쇄 / 탐색적 소지. 공격점은 위반 단정이 아니라 **기각·범위 제한·마스킹·열람제한이 필요한 과잉 신청**.
- 비밀보호: 덜 침해적 대안(양사 상호거래·특정 과세기간·문제 입출금 전후)을 구체로 적시 → 비례성 반박 재료.
- 인격권: 표현이 의혹인지 단정인지 / 자료 기초 / 전달 범위 / 반대자료 인지 후 반복 여부 4요소.
- 조문 번호를 적을 때는 core §7 원문 대조. 대조 못 했으면 조문 번호 없이 원칙 명칭만.

## 7. 산출물

1. 시간축·강도축 표 (§3)
2. D-01~D-05 카드
3. 법적 시사점 4트랙
4. **재판부 제시용 압축 논지** 1문단(blockquote): 출발점 → 확대 지점 → 확인/단정 병존 → 구조 판정("입증보다 탐색") → 요구사항(신청별 거래·금액·조항·손해·인과관계 특정, 범위 초과 자료 제한)
5. 추가 확인 필요 자료 목록(법원 결정·기관 회신 원문·후속 서면 연결·석명 여부)
6. **법적 판정 등급표**: 쟁점 / 현재 판정 / 이유. 판정 값은 `미확정 / 가능성 검토 / 과잉·부적절 신청 소지 / 강함` 중에서 쓰되 **각 행에 확신 % 병기**(어휘만 두는 것은 core §2 위반).
7. 작성 기준일 + "법원의 최종 법률판단을 대신하지 않는다" 선언.
