# SLDA §6.5 Stylistic Drift v0.1

상속: `slda-core`. verdict_mode = **`observe` 고정**. 변화의 존재·양·분포·진폭은 산출, **원인·진위·의도는 공백**.

> 어투가 바뀐 것은 데이터로 확정하되, 왜 바뀌었는지는 산출하지 않는다.

한 변곡점에는 최소 5개 원인이 경합한다(진술 전략 변화 / AI 도구 도입·교체 / 대필·구술 / 대리인 수정 / 사안 성격 변화). 하나로 좁힐 수 없으므로 원인 칸은 비운다.

## 1. 산출/미산출 경계

| 산출한다 | 산출하지 않는다 |
|---|---|
| "X 지점에서 직접화법→완곡체 이동" | "그러므로 회피/거짓" |
| "문장당 claim 수 급증" | "몰아붙였다 = 조작" |
| "변곡점이 초반부 집중" | "초반에 말을 맞췄다" |
| "단정↔완곡 급전환 폭 큼" | "확신 없다 = 허위" |
| "구간별 편차 커 다회 수정으로 **보임**"(이 한 곳만 헤지 허용) | "여러 손 = 대필·공모" |
| "1인칭↔3인칭 법률체 전환 지점" | "인격이 바뀌었다" |

## 2. 지표 6종 — 전부 기계적 집계

| § | 지표 | 정의 | 집계 |
|---|---|---|---|
| 6.5.1 | Claim Density | 한 종결 안 독립 사실·평가 개수 | 절 분리 후 술어핵 카운트 |
| 6.5.2 | Subject–Predicate Distance | 주어→대응 술어 어절 수 | 의존구문 또는 규칙 거리 |
| 6.5.3 | Nominalization Rate | 추상명사 종결·명사화 구문 비율 | 패턴 사전 매칭 / 전체 종결 |
| 6.5.4 | Assertion–Hedge Ratio | 직접 종결 vs 완곡 종결 비율, **어느 구간에서 뒤집히는가** | 종결어미 분류 |
| 6.5.5 | Subject-Mixing Index | 한 문장 내 교대 주체 수 | 문장 내 개체 주체 카운트 |
| 6.5.6 | Person Shift | 1인칭("저는")↔3인칭 법률체("피고는") 전환 지점·빈도 | 인칭 표지 분류 |

기존 엔진과의 경계: 6.5.1은 §6.1 전제 추출과 달리 **밀도만**; 6.5.4는 §6.4 표현강도(내용 세기)와 달리 **형식 비율만**; 6.5.5는 §6.3 귀속 이동과 달리 **문장 구조 층위만**.

## 3. 산출물

```
style_units.csv             문장별 6.5.1~6.5.6 원자료 (재현 근거)
stylistic_drift_report.md   변곡점 타임라인 + 분포·진폭·정제도 관찰
overlay_strength_style.md   §6.4 × §6.5 오버레이 — 두 곡선이 같은 지점에서 꺾이는 겹침만
```

- 변곡점 라벨은 **관찰 라벨만**("직접→완곡 전환", "claim 밀도 급증"). 원인 라벨 없음.
- 오버레이: "동시에 이동했다"는 사실. "그러므로 X"는 붙이지 않는다.
- **결론 문단(court_summary 대응)을 만들지 않는다.** 관찰 리포트가 최종 산출이다.

## 4. 입력

비정형 텍스트 전반(서면·계약 협상 라운드·연설·인터뷰·SNS 스레드·제안서 개정 이력). 파일명 `[화자]_문서제목_날짜_차수.md`. 시간·구간 순서는 core §1-3(재배열 금지).

## 5. 금지선·재현성

- 어투 변화로 거짓·조작·기망·의도 단정 금지(심리감정·거짓말탐지 영역 침범).
- 재현 담보는 `style_units.csv`뿐. 방법론 방어 문단은 만들지 않는다 — "규칙 기반, 재현 가능" 한 줄.
- 진행 중 소송 문서에 섞지 않는다. 제품 트랙이며 소송 종료 후 착수.
- 데모 제작 시 실명·식별정보 익명화.
