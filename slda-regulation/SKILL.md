# SLDA Regulation v0.1

상속: `slda-core`. verdict_mode = `observe`(변경의 존재·양·분포·방향까지, 입법 의도·위법 판단 공백). **data_class = public** — 공개 문서만. 실명·식별자가 섞인 입력(민원·소송 서면)은 이 모듈이 아니라 litigation/inquiry로 보낸다.

## 1. 입력 규격

- 문서 1건 = 1버전. 파일명 `[기관]_[규정명]_[시행일 YYYYMMDD]_[차수].md|txt|html`. 같은 규정의 버전을 시간순으로.
- 출처 URL·수집 일시·문서 해시(SHA-256)를 `versions.csv`에 고정. 공개 원문이 근거이므로 **해시 없는 버전은 등재하지 않는다.**
- 조문 단위로 분할: `article_id = 규정ID/장/조/항/호`. 분할 규칙은 결정적(정규식 사전). 분할 결과 행 수를 버전별로 기록.

## 2. 엔진

| 엔진 | 단위 | 산출 |
|---|---|---|
| 변경 원장 | 조문×인접 버전 | `ADD / DEL / MOD / MOVE / RENUM` + diff 비율. MOD는 어절 diff ≥ 1 |
| 표현강도 변화 (R-01 변형) | 조문 | 의무·요건 술어 사다리: 할 수 있다(0) → 노력한다(1) → 하여야 한다(2) → 하지 아니하면 안 된다·처벌(3). 버전 간 사다리 이동만 기록 |
| 주체귀속 이동 (R-02 변형) | 조문 | 의무자·결정권자·심사권자 주어 슬롯 변화. "기금은" → "이사장은" → "담당부서장은" 식 이동 |
| 공개현황 갭 | 규정 | 제·개정 사실(고시·공고·시행일) 대비 전문 공개 여부·공개 시점·공개 범위(전문/요약/목차만). `gap_days` = 시행일 − 공개일 |
| 참조 무결성 | 인용 | 조문이 인용하는 타 조문·상위법령이 해당 시점 버전에 실재하는지. 불일치는 `DANGLING_REF` |

## 3. 산출물

```
versions.csv            규정·버전·시행일·출처URL·수집시각·sha256·조문수
article_units.csv       article_id · version · text · subject_slot · strength(0–3)
change_ledger.csv       article_id · from_ver · to_ver · change_type · diff_ratio · strength_delta · subject_shift
disclosure_gap.csv      규정 · 제개정일 · 시행일 · 공개일 · 공개범위 · gap_days · 상태(공개/부분/미공개)
ref_integrity.csv       인용 위치 · 인용 대상 · 실재 여부 · DANGLING_REF
regulation_report.html  report-html 스캐폴드 — 변경 타임라인 · 강도 이동 히트맵(litigation §4 형식) · 갭 표 · 참조 무결성 표
```

## 4. 금지선 (모듈 고유)

- 개정 **이유·의도**를 쓰지 않는다. "강화됐다/완화됐다"는 사다리 이동 방향 서술까지만.
- 법적 효력·위법·무효 판단 금지. `DANGLING_REF`는 "해당 시점 버전에서 인용 대상을 찾지 못함"이지 하자 판정이 아니다.
- 공개 원문 외 자료(민원 회신, 소송 서면, 내부 문서) 혼입 금지 — 섞이면 data_class가 깨지고 트랙이 바뀐다.
- 공개현황 "미공개"는 **수집 시점 기준 확인 불가**로 표기하고 수집 시각을 붙인다.

## 5. 체크리스트

- [ ] 전 버전 sha256·출처URL 존재
- [ ] 조문 분할 규칙 사전 공개, 버전별 행 수 명기
- [ ] change_ledger 행 수 == 변경 조문 수 (리포트 헤더 카운트 검사)
- [ ] 강도 사다리 이동만 기록, 이유 서술 0건
- [ ] 입력에 식별자 regex(주민·전화·이메일·사업자) 0건 — 있으면 중단, 트랙 재지정

## 연동
- 신보 규정 공개현황(letscheck-sinbo)이 첫 적용처. 사이트 서버 → `/dispatch {"mod":"regulation","data_class":"public"}` → 전처리 지시문 없이 core+regulation(+report-html) 번들.
- inquiry 모듈과 결합 시(소송 트랙에서 규정 인용 검증) 이 모듈 산출(`ref_integrity.csv`)을 사실자료로 넘긴다 — 그때는 litigation 트랙의 data_class를 따른다.
