# SLDA Litigation v0.2

상속: `slda-core` §1–§9 전부. verdict_mode 기본 `determine`(당사자 제공용) — 제품 데모는 `observe`.

## 1. 입력 규격

- 여러 `.md`/`.txt` 동시 입력. 파일명 `[지위]_문서제목_날짜_차수.md` (지위 = 원고/피고/소외인/법원/외부기관).
- 분석대상 = 변론서면·신청서류만. **제외**: 증거, 계좌회신, 법원 심문서, 외부기관 회신, 계좌 "명의인" 표기.
- 첫 단계에 **ACTOR 진영 맵**을 박는다(이 사건의 고정 전제). 진영이 다른 인물이 같은 프레임으로 일괄 귀속되는지가 관찰 대상이므로 진영은 앵커다.

## 3. §6.4 표현강도 — 결정적 채점

신호 7축을 규칙 매칭으로 채점하고 각 문장의 매칭 신호를 원자료에 기록한다: **어미 / 추정 / 단정 / 법적 술어 / 형사법 프레임 / 부사 강도 / 외부기관 조회**. 척도 라벨은 core §2 (사실·가능성·추정의심·강한평가·확신).

- 서면별로 **평균·최고·80+ 건수** 3값을 표로. n이 작은 서면은 평균 해석 주의를 각주로.
- 변곡점 = 평균이 한 구간 이상 뛰는 서면. 변곡 서면은 §4 프레임·§6.3 귀속·비당사자 지칭 폭증과 **같은 서면인지** 대조한다 (앵커 사례: 2025.09.24 준비서면에 3축이 모두 겹침).
- 루브릭 세부 규칙은 비공개. 리포트에는 "결정적 규칙 채점 · 원자료 봉인" 한 줄.

## 4. 프레임 드리프트 — 히트맵

1. 원고(또는 분석 대상 진영)가 사용한 쟁점 프레임을 **상위개념 A~F**로 정의하고, 각 프레임의 **하위 단어 사전**을 리포트에 공개한다(빈도는 누구나 재계수 가능해야 한다).
2. 행 = 서면(시간순), 열 = 프레임(좌=초기·계약 → 우=후기·실질지배). 셀 = 하위 단어 서면별 출현 빈도 → 5단계 강도(없음/약함/등장/중간/강함).
3. 관찰 문장은 **"어느 프레임이 어느 서면에서 켜지고 꺼지는가"**까지. 예: "A 실손해·구상은 소장에서만 켜지고 이후 전부 꺼진다(25→1)."
4. **입증대상 이탈 검사:** 청구 성립에 필수인 프레임(예: 실손해)의 지칭이 붕괴하고 다른 프레임(폐업·의도·자금환류)이 대체하면 "입증대상 이탈 + 프레임 대체"로 등재. 이는 관찰이며 손해 존부 판단이 아님을 명기.
5. **결합 의존 검사:** 대상 주체 문장 중 제3자(소외인)와 한 문장에 결합된 비율을 센다(앵커: 64/103 = 62%). 결합 매개가 제거되면 어느 프레임이 무너지는지 구조로 기술.

## 5. 전제충돌 PC — 등재 조건 4개 전부

1. 동일 진영 내부일 것(같은 원고 서면 묶음).
2. 두 전제가 논리적으로 양립 불가.
3. **양쪽 다 본인 서면 워딩으로 확인**. 상대 반박은 근거가 아니다.
4. 각 전제에 출처(서면·일자·면).

중요도: 최강 = 자격·능력 부정 ↔ 그 주체의 행위·유용 주장 동시 사용(주체 공백) / 강 = 자기 기준 미적용(자료 미검토 ↔ 증거가치 선판단) / 중 = 근거 격하·변수 배제. PC-01만 풀카드(전제A/전제B/논쟁상 의미), 이하 컴팩트.

## 6. 리포트 분리 원칙 (핵심)

- **소외인편 · 피고편 절대 분리.** 합본은 원고의 "공모·실질동일" 프레임을 강화한다.
- 각 편은 그 주체를 지칭한 문장만 원자료로 한다(피고편 앵커: 정민하·복덕판 지칭 103문장).
- 두 편 사이 L1(날짜·수치·인용 동일) / L2(관찰 라벨·강조점 차별화) / L3(소결 의견 차이 허용).
