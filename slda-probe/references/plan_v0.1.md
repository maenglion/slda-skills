# SLDA 프로브 검출 오버레이 — 기획안 v0.1 (2026-09-09)

## 1. 목적
분쟁·협상·소송 커뮤니케이션에서 "상대가 알고도 응답하지 않은 것"을 계측한다.
단발 무응답은 노이즈지만, **반복 자극에 대한 반복 침묵은 신호**다 — 이를 결정적으로 판정하는 오버레이. slda-core 선행 로드, controversy/dispute/litigation 위에 얹는다.

## 2. 신규 선처리 필드 (2종)

| 필드 | 정의 |
|---|---|
| **PROBE_ID** | 동일 화자의 의미 유사 발화(반증 가능 형식)가 채널 불문 2회 이상 반복될 때 클러스터로 묶어 부여. 의미 유사 = 동일 명제 핵(예: "니 클로드 견적도 비슷했다") 공유. 채널(카톡/통화/메일)과 표면형이 달라도 동일 PROBE_ID |
| **RESPONSE_CLASS** | 각 회차에 대한 상대의 최초 반응 분류: `answer`(명제에 문면 응답) / `deflect`(화제·프레임 이탈) / `silence`(무응답) |

## 3. 침묵 판정 규칙 (결정적)
- 전사(통화): 자극 발화 직후 블록이 **동일 화자**면 `silence`. (연속 동일 화자 블록 = 사이 무응답의 구조적 증명)
- 카톡: 자극 후 상대의 다음 발화가 명제 핵을 참조하지 않으면 `deflect`, 24시간 내 미발화 또는 타 주제 재개 시 `silence`
- 경계 사례는 보수 처리(answer 쪽으로) — 오탐 방지 우선

## 4. 판정
- 클러스터 내 회차 수 n ≥ 3, (silence + deflect) / n ≥ 2/3 → **회피 확정(EVASION_CONFIRMED)** 플래그
- 회피 확정 + 이후 동일 명제에 대한 반대 단정 발화 존재 → **인지 후 부인(KNOWN_DENIAL)** 상위 플래그
- n = 2는 후보(EVASION_CANDIDATE)로만 등재, 확정 금지

## 5. 검증 사례 (원장_정민하 · KT-2026-0908)
- PROBE "니 클로드 견적도 유사" 클러스터 (상대 신뢰 채널 앵커링 적용 — 자극이 상대 본인의 클로드를 지시): 00:52 협업통화 19:52(silence, 직후 블록 동일 화자) → 20:01·20:08(silence 지속) → 20:10 최초 반응 `deflect`("말이 안 되시고, 바람 불어넣어") → 이후 카톡 반복분 무응답
- 후속 발화: "1200보단 훨씬 적을 것"(02:03 하향 단정) + "내가 어떻게 알아?"(02:04)
- 판정: EVASION_CONFIRMED + KNOWN_DENIAL 성립
- 보조 발견: 프롬프트 공정성 문면(14:23 "오빠가 핵심 DB 줬다고 다 얘기하고 있어") — "AI 편향" 반박의 반증으로 동시 등재 가능

## 6. 응용 이식
- **소송(litigation)**: 석명·구석명에 대한 무응답/이탈 반복 탐지 — 준비서면 간 "답하지 않은 질문" 원장화. 문서제출명령 신청의 필요성 소명 재료로 직결
- **협상(dispute)**: 상대의 내부 검증 결과 은폐 탐지 — 합의 구간을 알고도 누른 기록
- **§35 트랙**: 기관의 반복 질의 무응답 카운트 → §62 진정 시 "성실 답변 의무 해태" 정량 근거

## 7. 운용 원칙
- 프로브는 사후 검출뿐 아니라 **사전 설계 가능** — 단, 자극은 반증 가능 형식이어야 하고(예/아니오가 존재하는 명제), 유도신문형 금지
- **상대 신뢰 채널 앵커링(핵심 설계 원리)**: 자극의 명제 핵에 상대가 신뢰하는 검증 주체 자체를 포함시킨다(본 사례: "니 클로드 견적도 비슷했다" — 상대 본인의 도구). 효과: ① 긍정 = 명제 시인 ② 부인 = 반증 가능(해당 로그 제출 요구 성립) ③ 침묵 = 자기 신뢰 채널 앞의 침묵이므로 "상대 도구 편향" 반박 원천 차단. 세 방향 모두 정보를 산출하는 강제수 구조 — 이중 트랩 원칙의 프로브 적용
- 침묵의 의미 부여는 판정 플래그까지만. "왜 침묵했는가"(동기)는 산출하지 않는다 — 어투 드리프트 모듈과 동일한 원인 불산출 원칙
