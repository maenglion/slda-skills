# SLDA Probe v0.1 · 루브릭 R-05

상속: `slda-core`. verdict_mode = 본체 모듈을 따름. 산출은 판정 플래그까지 — **"왜 침묵했는가"는 공백**(stylistic-drift와 동일한 원인 불산출 원칙).

## 1. 목적
단발 무응답은 노이즈, **반복 자극에 대한 반복 침묵은 신호**. 이를 결정적으로 판정한다.

## 2. 선처리 필드 2종 (core §3에 추가)

| 필드 | 정의 |
|---|---|
| `PROBE_ID` | 동일 화자의 의미 유사 발화(반증 가능 형식)가 **채널 불문** 2회 이상 반복될 때 클러스터 부여. 의미 유사 = 동일 명제 핵 공유. 표면형·채널이 달라도 동일 ID |
| `RESPONSE_CLASS` | 각 회차에 대한 상대의 **최초** 반응: `answer`(명제에 문면 응답) / `deflect`(화제·프레임 이탈) / `silence`(무응답) |

## 3. 침묵 판정 (결정적)
- 전사(통화): 자극 직후 블록이 **동일 화자**면 `silence`. 연속 동일 화자 블록 = 사이 무응답의 구조적 증명. (transcript `ATTRIBUTION_GRADE` A만 사용)
- 카톡: 자극 후 상대의 다음 발화가 명제 핵을 참조하지 않으면 `deflect`; 24시간 내 미발화 또는 타 주제 재개 시 `silence`.
- 경계 사례는 `answer` 쪽으로 보수 처리 — 오탐 방지 우선.

## 4. 판정
- n ≥ 3 이고 (silence + deflect) / n ≥ 2/3 → `EVASION_CONFIRMED`
- EVASION_CONFIRMED + 이후 동일 명제에 **반대 단정** 발화 → `KNOWN_DENIAL` (상위)
- n = 2 → `EVASION_CANDIDATE`만. 확정 금지.

## 5. 설계 원리 — 상대 신뢰 채널 앵커링
사전 프로브 설계 시 자극의 명제 핵에 **상대가 신뢰하는 검증 주체**를 포함시킨다(예: "니 클로드 견적도 비슷했다"). 효과: 긍정 = 시인 / 부인 = 반증 가능(로그 제출 요구 성립) / 침묵 = 자기 신뢰 채널 앞의 침묵 → "상대 도구 편향" 반박 원천 차단. 세 방향 모두 정보를 산출하는 강제수. 자극은 예/아니오가 존재하는 명제여야 하며 유도신문형 금지.

## 6. 본체 연동
- dispute: 협상 전 상대 인지 상태 확정. R-10(issue_relation·확실성) 산출을 입력으로 받는다.
- litigation: 석명·구석명 무응답/이탈 반복 → "답하지 않은 질문" 원장 → 문서제출명령 필요성 소명 재료(slda-inquiry 연결).
- §35 트랙: 기관 반복 질의 무응답 카운트 → §62 진정 정량 근거.

## 7. 표시 규격 (report-html)
`pc` 카드 1개 = PROBE 1개: 헤더(PROBE-nn · 명제 핵 · 앵커링 채널) → 회차표(회차·시각·채널·자극 문면·반응 class·반응 문면) → probe-strip(회차 노드 + 반대 단정 노드) → 플래그 배지(`EVASION_CONFIRMED · n/n`, `KNOWN_DENIAL`) + 회피율. 자동 소견 말미에 "침묵의 동기는 산출하지 않는다" 고정.
