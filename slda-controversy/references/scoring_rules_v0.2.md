# SLDA-SNS 루브릭 점수 기준서 v0.2

기준: `SLDA_SNS_모듈_프롬프트_v0_1.md` P0·P7 + JMH-external run 1~4에서 실제 적용한 규칙을 수치화. 
v0.1에서 "미확정(total_king 이관)"이던 항목별 산출 규칙을 여기서 고정한다. 가중치·상한값은 v0.1 그대로.

---

## 0. 산식 · 척도 (v0.1 고정)

```
총점 = E1×0.25 + E2×0.20 + E3×0.20 + E4×0.15 + E5×0.10 + E6×0.10
```
- 게이트 상한을 E1–E6 각각에 먼저 적용(min(점수, 상한)) → 산식 → 반올림 정수.
- 척도: 0–20 붕괴 / 21–40 취약 / 41–60 부분 / 61–80 견고 / 81–100 강함.
- 반드시 코드로 검산. 검산값을 §07 각주에 남긴다.

## 1. 채점 범위

| 구분 | 정의 | 점수 영향 |
|---|---|---|
| 채점 대상 | 분쟁 세션(첫 문제 제기 발화 ~ 마지막 발화) | 전 항목 |
| 사실자료 | 사전 통화·전일 카톡·첨부 문서·AI 산출물 인용 | 채점 안 함. 채점 대상 발화의 **검증**에만 사용 → E2·E5 상태 이동 |
| 미제출 | 존재는 확인되나 원문 없음 | 의존 주장은 "검증 필요". 확정 금지 |

세션 경계는 달력일이 아니라 취침·활동 경계. 파일명 범위도 세션 타임스탬프.

## 2. 선처리 필드 (모든 채점 발화에 부착. 누락 시 채점 무효)

| 필드 | 값 | 판별 마커 | 영향 |
|---|---|---|---|
| FRAME_OWNERSHIP | self / adopted | "그럴거면" "~대로 하면" "~라면" · **미러링**: "똑같지 않냐" "나도 ~한 말인데" "그거랑 뭐가 달라" | adopted → RDX. E2 가점. 후퇴·E6 계상 금지 |
| SARC_ROLE | replace / garnish | 논증 자리에 왔는가(replace) / 논증 뒤에 붙었는가(garnish) | replace만 E6. 강도 무관 |
| INVOKE_MODE | explore / assert | "돌려봐, 틀리면 사과" = explore / "증거잖아" "이렇게 돼 있네" = assert | explore: 불리 수용 여부 → E4. assert: 산출물–주장 정합 → E2 |
| 사건축 | ①의미 ②전달·귀속 ③상태 프레임 (사안별 재정의) | LEVEL(화자 주장 축) ≠ ATTRIB(상대가 읽은 축) → 단계 혼동 | E1 |
| CHANNEL | 수신자 도달 / 제3자 문서 | "회사에 쓴 메일" "대표님," | 제3자 문서는 ①증거만. ②증거로 쓰면 E1 −4 |
| OBJECT_SUBSTITUTION | 유/무 | "이거나" "그거 말고" "일단 이거" | 유 → RET 논점 이동 |
| REPLY_TO | 직전 응답 대상 발화 ID | — | "난 됐고" 류의 대상 확정. 미확정 시 이동 분류 금지 |
| REFERENT | 지시 대상 = 원장 ID / 미해소 | — | 미해소 발화는 분류하지 않고 목록으로 뽑아 **채점 전** 일괄 질의 |

## 3. 이동 4종 (P5)

| 종류 | 정의 | 태그 |
|---|---|---|
| ADV | 근거 추가 / 사건 재정의 / 상대 근거 역전 / 반증조건 제시 | 4종 중 1 |
| RET | 결론 유지 + 받침대 격하·부인·무의미화 | 전제 부인 / 근거 격하 / 기반 이동 / 논점 이동 / 검증 거부 / 변수 배제 / 자기기준 위반 |
| RDX | adopted 프레임에서 출력을 보이고 기각 (미러링 포함) | 상대 근거 역전 |
| FIX | 반박 수용 → 결론 세기 인하·철회. **오류 실재 필수** | 결론 약화 / 자기 오류 철회 |

헤더 카운트 == 행 수. 불일치 시 재실행.

## 4. 전제충돌 등재 조건 (P6)

1. 동일 화자 내부 2. 논리적 양립 불가 3. **양쪽 다 본인 워딩** 4. 출처 ID. 
제외: adopted / 명시적 철회 선행(=FIX) / 상대 텍스트가 근거. 
중요도: 최강(근거 문서가 결론 배신) 강(자기 기준 미적용·자기 산출물 결함 인지 후 강행) 중(기준 비대칭·근거 격하·변수 배제) 약. 
**주의:** 상대에게 원칙 텍스트가 없으면 같은 행위라도 PC로 안 올라간다. 이 비대칭은 등재 조건 차이이므로 §01에 행위 대조표로 별도 노출한다.

## 5. 항목별 산출 규칙

각 항목 = base + Σ가감 → 0–100 클립 → 게이트 상한. 
규칙 산출값과 최종값의 차이는 **±5 이내 판정 조정**만 허용하고 사유를 sc-note에 적는다. ±5를 넘으면 규칙을 고친다(점수를 고치지 않는다).

### E6 논점 유지 (0.10)
replace 비율 r = replace 발화 / 채점 발화(해당 주체). **garnish·RDX·미러링은 분자에서 제외.**

| r | 구간 |
|---|---|
| 0 | 90–100 |

| 3–8% | 55–74 |
| 8–15% | 35–54 |
| 15–30% | 20–34 |

## 6. 게이트 G0

| 커버 | 판정 | 상한 |
|---|---|---|
| 3/3 | PASS | 100 |
| 2/3 + 나머지 "검정 필요" 명시 | PARTIAL+ | 95 |
| 1~2/3 | PARTIAL | 70 |
| 0/3 | FAIL | 50 |

△(간접·부분 응답)는 커버로 세지 않는다. 상한이 어느 항목에도 안 걸리면 각주에 "상한 미적용"을 적는다.

## 7. 상태표 (P8)

확정 = 관측 사실(원문 존재) ∪ 검산 결과. 
그 외: 가능성(b1) / 검증 필요(b2) / 판단 안 함(b0). 
사안의 진위·모멸성·역량·진단 등은 항상 판단 안 함. 
채점 결과를 사안 판정으로 승격 금지.

**맹난영 (PASS, 상한 100)**

| 항목 | 산출 | 최종 | 조정 사유 |
|---|---|---|---|
| E1 | 85 −1(17:07 이후 확장) = 84 | 84 | — |
| E2 | 60 +12(RDX 2) +12(역전 3) +4(17:07 대조) −8(동기 2) −9(미검증 3) = 71 | 72 | +1 |
| E3 | 90 −20(PC-03 강) −10(지점 2) −5(전후 양쪽) = 55 | 55 | — |
| E4 | 50 +15 +5(요구 2회) +10 +8(FIX) −2(철회 조건부) = 86 | 90 | +4 (검증 자료 자체 제출 15:38) |

| 총점 | 84×.25+72×.2+55×.2+90×.15+58×.1+38×.1 = **69.5 → 70** | | |

**정민하 (PARTIAL, 상한 70 — 미적용)**

|---|---|---|---|

## 9. 재현 체크리스트

1. 선처리 8필드 전 발화 부착 (REFERENT 미해소 목록 0)
2. 통화·문서 인벤토리: 파일명·길이·시각 확정 후 "어느 자료인가" 매칭
3. 카톡 주장 ↔ 사실자료 대조 (grep + 고유명사 퍼지)
4. P5 헤더 == 행 수
5. PC 전제 A·B 원문 ID
6. 항목 산출표 → 조정 ±5 이내 → 코드 검산 오차 0
7. 상태표 확정 칸 = 관측 ∪ 검산
8. 채점 금지 6건 위반 0

## 10. 미확정 (total_king)
