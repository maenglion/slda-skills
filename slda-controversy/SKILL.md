# SLDA Controversy v0.1 (patch a–d 반영)

상속: `slda-core`. verdict_mode = `rank` (논증 채점·순위. 사안 판정 없음).
실행 순서: **P2 → P3 → P4 → P5 → P6 → P7 → P8 → P1(요약, 마지막)**. 요약은 앞 섹션에서 확정된 것만 압축한다.

## P0 · 선처리 (core §3) — 4필드 필수

`FRAME_OWNERSHIP` · `SARC_ROLE` · `INVOKE_MODE` · `STAGE_LEVEL/ATTRIB`. 모든 발화에 부착 후 채점. 누락 시 무효.
추가: **인용 문서는 독립 주체**로 등재(예: `성륜수문서` ≠ `성륜수`). 이것이 "근거가 주장을 배신하는 구조"를 노출하는 유일한 방법이다.

## P2 · 지정 레이어 정의 + 게이트 G0

1. 관측 사건을 **구성요소 3개**로 정의한다(앵커 예: (a) 동시일치 (b) 반복 (c) 층 편중). 관측 사실에 포함된 요소를 빼고 정의한 모델은 **다른 사건에 답한 것**이다.
2. 주체별로 (a)(b)(c) 커버 여부 ○/△/✕ → PASS / PARTIAL+ / PARTIAL / FAIL.
3. 게이트 상한: PASS 100 / PARTIAL+ 95 / PARTIAL 70 / FAIL 40 (잠정값). **E1–E6에 먼저 상한 적용 후** 총점 계산. 상한이 실제 작동했는지(실측 < 상한?) 각주로 기록.
4. 관측 사실 표(공표 자료)는 채점 대상이 아니다. 별도 블록.

## P3 · 주체별 주요 주장

주체마다: 결론(최종 명제) / 근거(이론·계산 사슬) / 레이어 커버 / 최고강도 문장 1개(원문). 문서 주체는 자기한계 기재를 추가.
**사건정의 불일치 경보:** 계산이 정확해도 다른 사건의 확률이면 경보 블록으로 분리(앵커: 1위 단독일치 K=108.5 vs 동시일치 K≈6,900 → 64배).

## P4 · 시간축 주장 드리프트

주체별 타임라인. 각 스텝에 일자·이동 내용. 붉은 칸 = 근거 교체·격하·논점 이동, 푸른 칸 = 근거 추가·강화.
요약 문장 고정형: "결론 이동 n회 · 근거 교체 n회" / "결론 약화 n회 · 근거 추가 n회 · 후퇴 0회". 귀류는 후퇴로 계상하지 않는다고 명시.

## P5 · 전진 및 후퇴 — 후퇴 벡터

| 태그 | 정의 | 점수 방향 |
|---|---|---|
| ADV | 근거 추가·강화, 반증 조건 제시, 불리 결과 자기보고 | 가점 |
| RET(근거) | 결론 유지한 채 근거 격하·부인·무의미화, 검증 거부, 변수 배제, 논점 이동 | 감점 |
| FIX(결론) | 반박 수용·세기 하향·철회 | 가점 |
| RDX(귀류) | 상대 식 조건부 채택→출력 부조리→기각. FRAME_OWNERSHIP=adopted | E2 가점. 후퇴·이동 미계상 |

- 주체별 헤더 카운트(예: RET 6 / ADV 1 / RDX 0 / FIX 0) == 그 아래 행 수. **일치 검사 필수**(v0.1 실패 지점).
- 각 RET 행에 유형 태그(전제 부인 / 근거 격하 / 기반 이동 / 논점 이동 / 검증 거부 / 자기기준 위반 / 변수 배제).
- **가설 판정 레인:** 채점 임계 미만 주체(발화 1–2건)의 가설도 H-nn으로 레이어 3요소에 대고 설명/미설명 판정. 미통과라도 반증 가능한 형태면 기각이 아니라 `provisional` 존치.

## P6 · 전제충돌 PC — 등재 조건 4개 전부

1. 동일 화자 내부(문서와 인용자는 별개 화자 → 문서↔인용자 PC 성립)
2. 논리적 양립 불가
3. **양쪽 다 본인 텍스트 워딩**
4. 각 전제에 일자·출처

제외: adopted(귀류) / 명시적 철회 선행(FIX) — 제외 사유를 블록으로 남긴다.
중요도: 최강 = 근거 문서가 인용자 결론을 지지하지 않음 / 강 = 자기 비판 기준 미적용 / 중 = 근거 격하·기준 비대칭·변수 배제.
엔진 결함 발견 시 core §8 형식으로 기록.

## P7 · 평가항목 E1–E6

| 항목 | 정의 | 가중 |
|---|---|---|
| E1 사건정의 정합성 | 지정 레이어와 같은 사건을 다루는가 | 0.25 |
| E2 근거–결론 정합성 | 가져온 이론·계산이 본인 결론을 지지하는가. 상대 근거 역전은 가점 | 0.20 |
| E3 전제 일관성 | P6 등재 건수 반영 | 0.20 |
| E4 검증 수용성 | 반증 조건 제시·검증 요구 수용·수행·자기 오류 철회·불리 판정 공개. 봉쇄·거부는 여기서 감점 | 0.15 |
| E5 한계 명시 | 지적받기 **전에** 스스로 기재했는가 | 0.10 |
| E6 논점 유지 | **replace만 감점.** garnish 감점 금지. 비꼼 강도는 지표 아님 | 0.10 |

총점 = Σ(Eᵢ×wᵢ), 게이트 상한 선적용, 반올림 정수. **코드로 계산, 검산값 각주.**

채점 금지 6항(위반 시 재채점): ✕ 비꼼 강도로 E6 감점 / ✕ RDX를 E2·E3 감점 사유로 / ✕ 오분류 기반 FIX를 E4 가점으로 / ✕ 문서의 한계기재를 인용자 점수로 / ✕ 동일 사유 이중계상("반박 시 제가 옳습니다" = E4 봉쇄, E6 중복 감점 금지) / ✕ INVOKE_MODE 미구분 일괄 비대칭.

sc-note에 감점 사유·가점 사유·검증된 상대 계산 오류(숫자)·조정 이력 각각 명시.

## P8 · 시사점 + 상태표

시사점 6–7개, 각각 **번호 + 굵은 명제 + 숫자 근거**. 숫자 없는 시사점 삭제. 최소 포함: 문서/인용자 분리 점수 차 · 게이트가 순위 결정(정확한 계산+틀린 사건 사례) · PC가 본인 텍스트로 확정 · 후퇴 벡터 · 최대 분산 항목(항목별 폭) · INVOKE_MODE 불일치 · 엔진 결함.
상태표 4단계(core §6). "이상치 후보"는 **가능성**이지 확정 아님.
